# Requirements

## Goal

Team.md의 3-Agent 협업 계획을 기반으로 로컬 저장 HTML 가족포털을 만든다.

## Core Portals

- 로그인 메인 포털
- 스케줄 포털
- 자산 포트폴리오 포털
- 뉴스 포털

## Agent-Added Portal

- 가족 할일 포털

## Constraints

- 외부 서버 없이 실행한다.
- 브라우저 `localStorage`에 저장한다.
- 가족 코드와 비밀번호로 로그인한다.
- HTML, CSS, JavaScript만 사용한다.
- 기본 화면은 실제 포털이어야 하며 랜딩 페이지가 아니어야 한다.
- 핸드폰 화면에서 하단 탭과 터치하기 쉬운 입력/버튼을 제공한다.

## Acceptance Criteria

- 로그인 후 메인 포털로 진입할 수 있다.
- 가족 코드 또는 비밀번호가 틀리면 진입할 수 없다.
- 각 포털에서 항목을 추가하고 삭제할 수 있다.
- 저장된 데이터가 새로고침 후에도 유지된다.
- 메인 포털에서 핵심 집계가 갱신된다.
- 에이전트 회의가 현재 상태를 반영한 로그를 남긴다.
- 모바일 화면에서 메뉴와 주요 버튼이 겹치지 않는다.
