# Plan

## Summary

정적 HTML 앱으로 가족포털을 구현하고, Planning, Development, Verification 에이전트가 현재 데이터 상태를 점검하는 회의 포털을 포함한다.

## Tasks

1. `index.html` 화면 구조 작성
2. `styles.css` 반응형 포털 UI 작성
3. `app.js` localStorage 저장 및 렌더링 구현
4. 가족 할일 포털 추가
5. 에이전트 회의 로그 구현
6. 가족 코드와 비밀번호 로그인 구현
7. 모바일 하단 탭과 안전영역 최적화
8. 문법 검증 및 파일 구조 확인

## Acceptance Criteria

- 로그인, 스케줄, 자산, 뉴스, 가족 할일, 에이전트, 설정 화면이 존재한다.
- CRUD 데이터는 localStorage 키별로 분리된다.
- 가족 코드와 비밀번호 해시가 localStorage에 저장된다.
- 모바일에서는 내비게이션이 하단 고정 탭으로 작동한다.
- JSON 내보내기와 가져오기가 가능하다.
- 에이전트 회의는 Planning, Development, Verification 메시지를 모두 생성한다.

## Decisions

- 추가 포털은 `가족 할일 포털`로 결정한다.
- 뉴스 포털은 외부 API 없이 가족이 직접 저장하는 뉴스 클립 방식으로 구현한다.
- 자산 포털은 자산과 부채 항목을 함께 저장하고 순자산을 계산한다.
- 로그인은 가족 코드와 비밀번호를 필수로 하고, 구성원 이름은 표시 이름으로 사용한다.
- 모바일 메뉴는 상단 공간을 차지하지 않도록 하단 고정 탭으로 배치한다.
