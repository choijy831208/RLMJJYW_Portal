    목표

    학습 방향

    • 무료 한국어 유튜브/공개 자료를 우선 사용한다.
    • 유료 API는 선택 과제로 둔다.
    • 연구자 수준이 아니라, 직접 AI 앱을 만들 수 있는 실전 입문 완성을 목표로 한다.

    최종 산출물

    • 개인 문서 Q&A 챗봇/RAG 프로토타입
    • 문서 검색, 근거 문단 표시, 출처 표시
    • 문서에 없는 질문에는 자료에서 찾을 수 없음 반환

    성공 기준

    • AI, ML, DL, LLM의 차이를 비전공자에게 5문장으로 설명할 수 있다.
    • 지도학습, 비지도학습, 강화학습, 과적합, RAG를 자기 말로 설명할 수 있다.
    • PyTorch 기초 실습 노트북 1개를 직접 실행하고 핵심 코드를 설명할 수 있다.
    • 개인 문서 3개 이상을 넣고 한국어 질문에 관련 근거 문단을 찾아주는 앱을 만든다.

    핵심 학습 자료

    • 생활코딩 머신러닝1: AI/머신러닝 개념 입문
    • 모두를 위한 딥러닝 시즌2 - PyTorch: PyTorch와 딥러닝 기초 실습

    최종 앱 스펙

    이름

    내 공부 노트 Q&A 챗봇

    입력

    • 개인 문서: .txt, .md
    • 선택 확장: .pdf
    • 사용자 질문: 한국어 자연어 질문

    출력

    • 답변 초안
    • 근거 문단
    • 출처 파일명
    • 근거가 없을 때: 자료에서 찾을 수 없음

    무료 기본형 동작

    1. 폴더 안의 개인 문서를 읽는다.
    2. 문서를 문단 또는 고정 길이 chunk로 나눈다.
    3. 질문과 chunk를 TF-IDF 또는 무료 임베딩 방식으로 비교한다.
    4. 유사도가 높은 근거 문단 3개를 보여준다.
    5. 유사도가 낮으면 답을 만들지 않고 자료에서 찾을 수 없음을 반환한다.

    선택 확장형 동작

    • API 키가 있을 때만 LLM 답변 생성을 연결한다.
    • LLM에는 검색된 근거 문단만 전달한다.
    • 근거에 없는 내용은 추측하지 않도록 프롬프트에 명시한다.
