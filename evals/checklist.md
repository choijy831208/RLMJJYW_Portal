# Checklist

## Login

- 첫 로그인에서 가족 코드와 비밀번호를 입력하면 포털로 진입한다.
- 다음 로그인에서 같은 가족 코드와 비밀번호로 진입한다.
- 잘못된 가족 코드 또는 비밀번호는 차단된다.
- 구성원 이름이 사이드바에 표시된다.
- 로그아웃 후 로그인 화면으로 돌아간다.
- 로그인 화면에서 로컬 초기화를 실행할 수 있다.

## Schedule

- 일정을 추가할 수 있다.
- 일정 목록에 날짜, 시간, 담당자, 분류가 표시된다.
- 일정을 삭제할 수 있다.

## Assets

- 자산과 부채를 추가할 수 있다.
- 총 자산, 총 부채, 순자산이 계산된다.
- 자산 배분 막대가 표시된다.

## News

- 뉴스 제목, 출처, 분류, 링크, 메모를 저장할 수 있다.
- 분류 필터가 작동한다.

## Tasks

- 할일을 추가할 수 있다.
- 완료 상태를 전환할 수 있다.
- 진행 중, 전체, 완료 필터가 작동한다.

## Agents

- 회의 실행 시 세 에이전트 메시지가 갱신된다.
- 결정 로그가 추가된다.

## Settings

- JSON 내보내기가 가능하다.
- JSON 가져오기가 가능하다.
- 초기화가 localStorage 데이터를 삭제한다.

## Mobile

- 하단 탭이 화면 아래에 고정된다.
- 하단 탭이 저장 버튼이나 목록 삭제 버튼을 가리지 않는다.
- 하단 탭을 눌렀을 때 새 포털 내용이 화면 맨 위에서 시작된다.
- 입력창을 터치해도 화면이 과도하게 확대되지 않는다.
- 상단바 제목과 샘플 데이터 버튼이 겹치지 않는다.
- 390px 이하 화면에서 집계 카드가 1열로 전환된다.
