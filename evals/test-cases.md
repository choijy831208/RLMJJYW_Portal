# Test Cases

## TC-001 로그인

1. `index.html`을 연다.
2. 가족 코드와 비밀번호를 입력한다.
3. `입장`을 누른다.

Expected:

- 메인 포털이 표시된다.
- 사이드바에 가족 이름과 구성원 이름이 표시된다.

## TC-001B 로그인 실패

1. 로그아웃한다.
2. 잘못된 가족 코드 또는 비밀번호를 입력한다.
3. `입장`을 누른다.

Expected:

- 포털에 진입하지 않는다.
- 오류 안내가 표시된다.

## TC-002 localStorage 유지

1. 스케줄을 1개 추가한다.
2. 브라우저를 새로고침한다.

Expected:

- 추가한 스케줄이 유지된다.

## TC-003 에이전트 회의

1. 에이전트 포털을 연다.
2. `회의 실행`을 누른다.

Expected:

- Planning, Development, Verification 메시지가 갱신된다.
- 결정 로그가 1개 추가된다.

## TC-004 데이터 내보내기

1. 설정 포털을 연다.
2. `내보내기`를 누른다.

Expected:

- JSON 데이터가 텍스트 영역에 출력된다.

## TC-005 모바일 레이아웃

1. 브라우저 개발자 도구에서 390px 이하 모바일 너비로 전환한다.
2. 메인, 스케줄, 자산, 뉴스, 가족 할일 포털을 차례로 연다.
3. 입력창과 저장 버튼을 확인한다.

Expected:

- 메뉴가 하단 탭으로 표시된다.
- 주요 버튼과 입력창이 하단 탭에 가려지지 않는다.
- 텍스트와 버튼이 서로 겹치지 않는다.
